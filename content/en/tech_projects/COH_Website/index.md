## Overview
Communications On Hold produces custom voice content for businesses: on-hold messaging, IVR and call-routing prompts, and radio commercials. Customers choose voices and music by listening to samples, so the website is built around a large audio library that has to be easy to browse on a phone as well as on a desktop.

[Visit the live site](https://communicationsonhold.com)

## What I Built
- Designed, built, and deployed the site with Hugo (a heavily customized HugoBlox theme), version-controlled on GitHub with continuous deployment through Netlify
- Wrote a custom audio-library component: a nested accordion of music, voice, and message samples that stays easy to use on mobile and desktop
- Wrote custom page blocks (page header, impact cards, contact card) and a custom CSS theme
- Configured the Netlify build with site-wide search (Pagefind) and 301 redirects from the company's .net and .org domains to .com

## Design Choices
- Built around how customers actually use the site: listening to and comparing samples before they decide what's best for their project
- A static site keeps pages fast and hosting simple
